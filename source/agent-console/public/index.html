    Swarms
            
            
            
            
            
    Members are drawn from the subagents below and keep their models and access. Ask for one in a chat, for example "use a swarm to find the cause". When the message limit is reached, members stop talking and write their final reports.
    
          
    
          
    OpenRouter needs an API key before these agents can run. 
    
          
    
          
    Subagents work in the chat's project with their own model and history. They never get more access than the chat: Read only subagents can't edit files, and editing subagents stay inside the workspace sandbox. Their usage counts toward the chat. Changes apply to the next delegation.

    Usage metrics
          
          
    Subscription percentages are account-wide. The bar shows the five-hour window; open Usage for weekly usage and the change since this chat was created. That change can include other chats or devices, so it is only a thread estimate. Older chats without a starting snapshot begin tracking when first viewed.
    
          
    
        
    
        
    Background generation
          
          
          
          
          
    Memory stays project-scoped and is retrieved only when a chat needs prior context. One-off chats are excluded. Local chats use their own model and server for titles and memory.
    
        
    
        
    
        
    
        
    Local capabilities
          
          
          
    Capabilities are lazy and apply to new chats. macOS asks for Automation access the first time one runs.
